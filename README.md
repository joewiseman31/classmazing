# Classmazing

A projected, fully customizable digital clip chart for elementary classrooms — and the suite of classroom reinforcement widgets it grows into.

Live at [classmazing.com](https://classmazing.com).

## What it is

Classmazing keeps the physical clip-chart experience teachers and students love — the chart lives on the wall, kids see their clips move, the whole class watches in real time — but adds a quiet data layer underneath that captures every movement with millisecond precision.

The hero feature: **parent-friendly Daily Reports** that read like a thoughtful note from the teacher, not a behavioral rap sheet.

## What's here today

- Multi-class support — for specialists, departmentalized teachers, and tutors
- Drag-and-drop that works on mice, touchscreens, smart boards, and styluses (Pointer Events)
- Four themes: Classic Kitchy, Ocean, Jungle, Boho Modern
- PDF reports — Today's Snapshot, Student Report (with time-of-day patterns + co-mover correlations), Class Summary, Daily Parent Report
- Substitute Mode — hand the room off to a sub without giving up the keys
- Local data persistence + JSON export/import for backups

## What's next

- Marble jar widget (whole-class collective accountability)
- Seating chart
- Cloud accounts and cross-device sync
- Stripe subscriptions and the Plus tier

## Tech

Single static HTML file. No build step. Deployed via Vercel.
